## 🚀 最简单的使用方法

### 方法1：直接运行超简脚本
```bash
# 1. 下载脚本
curl -fsSL [脚本地址] -o install-clawd.sh

# 2. 添加执行权限
chmod +x install-clawd.sh

# 3. 运行安装（使用淘宝镜像）
./install-clawd.sh

# 4. 或指定官方镜像
./install-clawd.sh https://registry.npmjs.org
```

### 方法2：使用完整打包
```bash
# 1. 下载打包文件
curl -fsSL [打包地址] -o clawd-installer.tar.gz

# 2. 解压
tar -xzvf clawd-installer.tar.gz

# 3. 进入目录
cd clawd-installer

# 4. 运行安装
./install-clawd.sh
```

## 🔧 安装后的操作

安装完成后：
1. **运行配置向导**
   ```bash
   openclaw-cn onboard
   ```

2. **启动服务**
   ```bash
   openclaw-cn gateway start
   ```

3. **查看状态**
   ```bash
   openclaw-cn status
   ```
